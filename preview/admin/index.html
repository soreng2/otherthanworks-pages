사이트 관리

관리 화면 미리보기
아래에서 글을 쓰고 파일을 첨부할 수 있습니다. 현재는 내 브라우저 임시저장까지 가능하며, 고객 사이트 공개에는 계정·저장소 연결이 필요합니다.

문의함

연결 후 새 문의·확인 중·처리 완료 상태와 문의 내용을 여기서 확인합니다. 현재는 저장소 미연결로 문의를 접수하거나 목록을 조회할 수 없습니다.

페이지 문구 편집

페이지의 제목·소개·메뉴·버튼·안내 문구를 검색해 수정합니다. 같은 원문이 여러 곳에 있으면 함께 바뀝니다. 수업별 내용·후기·게시물은 해당 관리 메뉴에서도 편집할 수 있습니다.

문구를 선택하고 바꿔 볼 수 있습니다. 현재는 저장소 미연결로 저장·공개되지 않습니다.

새 글 쓰기

제목과 내용을 쓰고 사진·영상을 첨부해 주세요. ‘내 브라우저에 임시저장’을 누르면 나중에 이어 쓸 수 있습니다. 임시저장은 이 기기·브라우저에만 보관되며 고객에게 공개되지 않습니다. 브라우저 데이터를 삭제하면 함께 지워집니다.

글 작성

JPG·PNG·WebP 10MB 이하 / MP4·WebM 50MB 이하 / 합계 20개

임시저장은 글 1개를 보관하며 다시 저장하면 이전 글을 대체합니다. 사이트에 공개하는 기능은 계정·저장소 연결 후 사용할 수 있습니다.
