# 사진·영상 넣는 곳

여기에 파일을 넣어주시면 사이트에 반영할게요. 폴더에 그냥 드래그해서 넣으시거나, 채팅으로 저한테 바로 보내주셔도 돼요 (그럼 제가 알맞은 폴더로 옮겨둘게요). 파일 이름은 신경 안 쓰셔도 됩니다.

## 어디에 뭘 넣으면 되는지

- `hero/` — 홈페이지 맨 위 대표 이미지 1~2장. 공간이나 수업 분위기가 잘 보이는 사진.
- `space/` — 작업실·수업 공간 사진 1~2장.
- `about-소랭/` — 소랭 본인 사진(작업하는 모습, 인물샷 등). ABOUT 페이지용.
- `work-대표작업/` — 대표 작업물(콘텐츠·브랜딩·포트폴리오 결과물) 4장 정도.
- `classes/드로잉루틴, 콘텐츠반, 포트폴리오반, 픽처포지, 이모티콘반` — 각 클래스 실제 작업 예시. 클래스당 2~3장이면 충분해요.
- `reviews-수강생후기/` — 공개 동의받은 수강생 후기용 사진·캡처. **동의 안 받은 건 넣지 마세요** — 동의된 것만.

영상은 `site/videos/intake/`에 넣어주시면 됩니다 (수업 하이라이트, 릴스 클립 등).

## 참고

전체 권장 장수(`30-knowledge/02-brand/WEBSITE_DIRECTION.md` 기준): 공간/수업분위기 1~2장, 대표 클래스 작업 4장, 콘텐츠·브랜딩·포트폴리오 결과 4장, 공개 동의 수강생 결과 2장 — 합쳐서 10~12장 정도면 1차로 충분해요. 한 번에 다 안 채워도 되고, 들어오는 대로 순서대로 반영할게요.
