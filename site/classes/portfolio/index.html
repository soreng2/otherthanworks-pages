CURRICULUM
8주 동안 완성하는 것

  • 1-2포지셔닝 진단과 시장 방향 — 어떤 작가이며 누구에게 필요한 그림을 그리는지 정하기
  • 3-5대표작 3~5개 기획·제작 — 시장성과 활용처가 있는 작업으로 확장
  • 6PDF 포트폴리오 편집 — 표지, 작가 소개, 작품 설명문, 문의 대응 메시지
  • 7제안서·견적서·문의 응답 템플릿 준비 — 포트폴리오를 일로 연결하기
  • 8공개형 Notion 포트폴리오 사이트 구성과 실제 제안 발송 준비

졸업 결과는 포트폴리오 완성, 실행 결과는 실제 제안 발송입니다. 작품집이 아니라 “어떤 일을 맡길 수 있는지” 보여주는 도구로 만듭니다.
