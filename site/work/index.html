CLASS WORK
수업에서 나온 결과물

공개 동의를 받은 수강생 작업부터 순서대로 올립니다. 얼굴·이름은 동의 범위 안에서만 사용합니다.

WORK IN PROGRESS

공개 가능한 실제 작업 이미지를 준비하고 있습니다. 대표 클래스 작업, 콘텐츠·브랜딩·포트폴리오 결과를 포함해 약 10~12장을 목표로 모으는 중입니다.

STUDIO WORK
스튜디오 프로젝트

브랜드·그래픽·콘텐츠 디자인 프로젝트는 스튜디오 페이지에서도 확인할 수 있습니다.

A CALENDAR STUDY — NOT A CLIENT PROJECT

현재 화면 구성을 위한 그래픽 시안만 있는 상태이며, 실제 고객·수강생 작업물로 소개하지 않습니다. 진행 중인 프로젝트의 사용 동의가 확인되는 대로 교체합니다.

가장 최근 작업은 Instagram에서 먼저 공개됩니다.
