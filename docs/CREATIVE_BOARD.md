# 수업 공고·후기 중심 시안

요청 참고 URL은 https://ilovecreatives.com/ 이다. 일반 접속 및 권한을 높인 재시도 모두 환경 프록시 CONNECT 403으로 실패했다. 실제 화면·코드·이미지를 읽거나 복제하지 않았다. 따라서 이 결과는 그 사이트의 정확한 재현이 아니라 사용자가 요구한 수업 공고·후기 중심 구성을 구현한 독립 시안이다. 구체적인 화면 비교에는 사용자 제공 스크린샷/자료가 필요하다.

기존 확정 수업 정보, 스마트스토어, 관리자, Instagram 연결 방식을 유지하면서 홈페이지 구성을 다음처럼 바꿨다.

- 큰 한글 타이포그래피, 안내 쪽지와 정규반 공고, 버터·블루·피치 배경.
- 수업 분야 필터와 포스터형 공고 카드. 기수·기간·가격·일정을 함께 노출한다. 모집 중/마감일/잔여석을 지어내지 않는다.
- 관리자가 공개한 수업의 첫 번째 사진을 공고 대표 이미지로 사용한다. 사진이 없으면 자체 제작한 타이포그래피/도형 포스터를 표시한다. 실제 수강생 작품으로 가장하지 않는다.
- 수강 후기와 작업 예시는 서로 다른 섹션. 후기는 사진, 제목, 인용문 본문, 공개 이름, 관련 수업으로 표시한다. 자료가 없으면 준비 안내만 보여준다.
- Instagram과 스튜디오를 후속 섹션으로 연결한다. 모션 줄이기/키보드 동작을 유지한다.

## 관리자 변경

기존 SQL 적용 후 `supabase/review-profiles.sql`을 실행한다. 후기에 선택 항목 `author_name`(80자), `course_label`(120자)를 추가하며 기존 자료는 빈 값으로 유지한다. 관리자에서 등록/수정 가능하다. 저장소 연결과 실제 권한 검증은 여전히 필요하다. 실제 작성자 이름이나 성과를 추정해 채우지 않았다.

수업 관리에서는 첫 번째 사진이 대표 이미지가 되므로 포스터/작업 이미지를 첫 순서에 둔다. 공개 반영 후 홈과 클래스 공고에서 사진·수업명·설명·기간·가격·일정이 갱신된다. 공개 데이터/이미지 링크를 4분마다 새로 읽는다.

## 검증

단위 테스트36개, lint/프로덕션 빌드 통과. Chromium 모의 저장소에서 후기 이름·수강 과정 등록과 인용문 렌더링, 수업 공고 대표 사진/정보 로딩을 확인했다. 홈·클래스·관리자·WORK·후기 5경로 × PC1440/모바일390 총10개 화면에서 가로넘침/JS 오류 및 axe WCAG2 A/AA·2.1AA 자동 검사 통과. 분야 필터 전환, 동작 줄이기, JS 비활성 시 콘텐츠 표시도 확인했다. 원격 저장소 SQL 권한/실제 업로드/실결제/실제 Instagram 재생은 미검증 상태다.
