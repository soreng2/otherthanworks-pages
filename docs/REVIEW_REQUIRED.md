# 운영 전 확인 사항

이 문서는 미확정 사항과 운영자 질문을 모으는 유일한 위치입니다. 구조화된 상태는 `content/site.ts`의 `requiresConfirmation`에 보존합니다. 우선순위: **비주얼 검수 → 운영 내용 확정 → 실수신 문의 테스트 → 결제 연동 → Vercel 배포 → DNS/SSL 확인**. PC·모바일 캡처는 [화면 검수 기록](VISUAL_REVIEW.md)에서 확인합니다.

## 1. 원본과 비주얼 — 현재 작업 대상

- 인계 문서의 Next.js MVP, README, 검토 문서, `folder-stack.webp`가 현재 저장소와 원격 main에 없었습니다. 현재 코드는 지정 팔레트로 새로 구현한 초안입니다.
- 현재 `folder-stack.svg`와 달력 이미지는 새로 만든 그래픽 시안이며 실제 강사·수강생·고객 작업물이 아닙니다. WK Creative Studio의 그래픽·코드는 사용하지 않았습니다.
- 원본 MVP는 다른 저장소·브랜치·압축파일에 있나요? 원본 폴더 이미지와 사용 허용된 이미지·크레딧은 어디에서 받을 수 있나요?
- 브랜드 문구와 프로그램의 한글 표기, 스튜디오 서비스 범위, 현재 비주얼 초안을 사용할 수 있나요?
- 1440px/390px 화면에서 새 폴더 그래픽과 텍스트를 검수합니다. 원본 `folder-stack.webp`의 실제 비율·텍스트 정렬 검수는 파일이 없어서 미실행입니다. 교체 시 다시 검수해야 합니다.

## 2. 클래스 운영 정보 — 미확정

대상: `content-studio`, `portfolio-ready`, `portfolio-build`, `pictureforge`.

- 각 프로그램의 공식 이름·소개·커리큘럼·강사·시간·장소·온라인 여부는 무엇인가요?
- 정원, 수강 조건, 날짜, 모집 시작·마감, 현재 등록 상태는 무엇인가요?
- 수강료, 부가세, 할인·취소·환불 기준은 무엇인가요?
- 현재 설명은 초안입니다. 미확정 가격·일정은 `null`이며 홈페이지는 ‘준비 중’으로 표시합니다.
- 수강생 후기와 성과, 강사 소개·작업물은 실제 자료 및 공개 동의 확보 후에만 추가합니다.

## 3. 법적 안내와 문의 실수신 — 미연결

- 사업자명·대표자·사업자등록번호·통신판매업 신고·주소·연락처는 무엇인가요?
- 개인정보 보호 담당자, 수집 목적·항목, 보유 기간, 거부 권리, 위탁·국외 이전 고지를 어떻게 확정할까요?
- 실제 수신 이메일과 webhook 제공자는 무엇인가요? Resend를 직접 사용할지, 인증된 webhook으로 받을지 확정이 필요합니다.
- Upstash Redis 운영 계정·보유 정책과 Vercel 배포 지역은 무엇인가요?
- 비밀 값은 채팅·문서·Git에 쓰지 말고 배포 플랫폼의 보안 설정에 입력합니다.
- 현재 `inquiriesEnabled=false`, `legalApproved=false`. 양식은 비활성이며 API는 설정이 없으면 503으로 거부합니다. 실제 접수·전달을 완료했다고 표시하지 않습니다.
- 구현된 보안: 출처 제한, 서버 입력 검증, 16KiB 본문 제한, honeypot, 명시적 동의, HTTPS·인증 webhook, timeout·리디렉션 차단, 원자적 Redis rate limit. 운영 전 실제 제공자 계약과 처리 방식 검토가 필요합니다.
- 실수신 E2E는 아직 미실행. 테스트용 계정·고지에서 정상 전송, 수신함 도착, 실패·중복·429를 검증한 후에만 `INQUIRY_DELIVERY_VERIFIED` 및 기능 플래그를 활성화합니다. 현재 `/legal`은 색인 제외된 초안입니다.

## 4. 결제 — 미구현·미연결

- 결제 제공자, 상품별 가격·URL, 테스트 계정, 취소·환불 정책은 무엇인가요?
- 현금영수증·세금 처리·신청 상태 관리 방식은 무엇인가요?
- 서버에서 상품·금액·통화를 검증하고 웹훅 서명·중복 이벤트·환불을 처리해야 합니다. 결제 리턴 URL만으로 수강 등록을 확정하면 안 됩니다.
- 확정 전 결제 버튼·결제 완료 화면·가짜 체크아웃을 만들지 않습니다. `paymentUrl=null`을 유지합니다.

## 5. SNS·추적

- 공식 Instagram `https://www.instagram.com/other.than.works/`만 연결했습니다. 외부 탭 링크에는 관련 안내와 `noopener noreferrer`를 적용합니다.
- YouTube ‘딴짓 실험실’ 공식 URL은 무엇인가요? 미확인 링크는 표시하지 않습니다.
- GA4/Meta Pixel 도입 목적·동의·고지·전환 정의는 무엇인가요? 확정 전에는 어떤 추적 코드도 설치하지 않습니다.

## 6. Vercel·도메인 — 미배포

- 연결할 Vercel 팀·프로젝트와 배포 권한은 무엇인가요?
- `otherthanworks.com`의 DNS 관리 서비스와 기존 레코드·메일 설정은 무엇인가요?
- Preview에서 운영 내용을 먼저 확정한 후 Production에 배포합니다. DNS 변경은 기존 메일·다른 서비스를 보존하면서 Vercel이 실제 제시하는 값으로 진행합니다.
- `www.otherthanworks.com`은 목표 canonical 도메인입니다. 현재 DNS·SSL 연결 및 서비스 운영은 확인되지 않았습니다.
- 배포 후 루트/www 리디렉션, HTTPS 인증서, sitemap, robots, 실제 OG 이미지, 404, 문의 E2E를 다시 확인합니다.

## 검증 상태

- `npm install`, 잠금파일 기준 `npm ci`, `npm run lint`, `npm run typecheck`, `npm run build` 통과.
- `npm test`: 입력 검증과 모의 API 테스트 **30개 통과, 실패·건너뜀 0**. 실제 외부 전송은 하지 않았습니다.
- 13개 지정 경로를 1440×1000 / 390×844에서 검사한 **26개 화면 통과**. HTTP 200, 이미지 로딩, 단일 h1, 가로 넘침 없음, JavaScript 오류 없음. 키보드 본문 이동, 모바일 메뉴 열기·Escape·링크 이동과 문의 비활성 상태를 확인했습니다.
- axe-core의 WCAG 2 A/AA 및 2.1 A/AA 자동 검사: 대표 10개 경로 × 두 화면 = **20개 화면에서 검출 위반 0**. 자동 검사 범위의 결과이며 전체 수동 접근성 인증을 의미하지 않습니다.
- 비활성 API 503, 외부 출처 403, 잘못된 형식 415, 미존재 클래스 404 확인. 기존 설문·수업 자료 및 리디렉션 응답 확인.
- 대표 경로 canonical, 문의·법적 초안 noindex, sitemap 10개 항목과 PNG OG 응답 확인. `npm audit --omit=dev --audit-level=high`: 발견 취약점 0.
- 개발 서버 및 프로덕션 서버에서 홈페이지 응답 확인. 클라우드 환경의 `install_script` / `start_skill`을 Next.js 기준으로 저장했습니다. 환경 게시는 아직 하지 않았습니다.
- 원본 이미지 정렬, 외부 webhook/이메일 수신, 결제, Vercel 배포, DNS·SSL: 미검증.
- 회원·멤버십·수강생 프로젝트 업로드: 실제 수요 확인 전 개발하지 않습니다.
