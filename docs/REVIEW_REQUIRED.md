## 검증 상태

- GitHub Pages 검토용 사이트 공개 완료: https://soreng2.github.io/otherthanworks-pages/preview/ . 별도 정적 배포의 26개 화면 검사 및 공개 HTTPS 13개 페이지·연결 자원 검사가 통과했습니다. [배포 기록](PREVIEW_DEPLOYMENT.md) 참조. Vercel 정식 배포와 가비아 DNS는 미변경입니다.

- `npm install`, 잠금파일 기준 `npm ci`, `npm run lint`, `npm run typecheck`, `npm run build` 통과.
- `npm test`: 입력 검증과 모의 API 테스트 **30개 통과, 실패·건너뜀 0**. 실제 외부 전송은 하지 않았습니다.
- 13개 지정 경로를 1440×1000 / 390×844에서 검사한 **26개 화면 통과**. HTTP 200, 이미지 로딩, 단일 h1, 가로 넘침 없음, JavaScript 오류 없음. 키보드 본문 이동, 모바일 메뉴 열기·Escape·링크 이동과 문의 비활성 상태를 확인했습니다.
- axe-core의 WCAG 2 A/AA 및 2.1 A/AA 자동 검사: 대표 10개 경로 × 두 화면 = **20개 화면에서 검출 위반 0**. 자동 검사 범위의 결과이며 전체 수동 접근성 인증을 의미하지 않습니다.
- 비활성 API 503, 외부 출처 403, 잘못된 형식 415, 미존재 클래스 404 확인. 기존 설문·수업 자료 및 리디렉션 응답 확인.
- 대표 경로 canonical, 문의·법적 초안 noindex, sitemap 10개 항목과 PNG OG 응답 확인. `npm audit --omit=dev --audit-level=high`: 발견 취약점 0.
- 개발 서버 및 프로덕션 서버에서 홈페이지 응답 확인. 클라우드 환경의 `install_script` / `start_skill`을 Next.js 기준으로 저장했습니다. 환경 게시는 아직 하지 않았습니다.
- 원본 이미지 정렬, 외부 webhook/이메일 수신, 결제, Vercel 배포, DNS·SSL: 미검증.
- 회원·멤버십·수강생 프로젝트 업로드: 실제 수요 확인 전 개발하지 않습니다.
