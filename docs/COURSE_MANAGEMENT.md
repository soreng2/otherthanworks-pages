# 수업 운영 관리

## 모집 상태와 목록 순서

`supabase/course-enrollment.sql`을 `courses.sql` 이후 적용합니다. 기존 수업은 `일정 문의` 상태로 유지됩니다. 관리자에서 실제 모집 상황에 맞춰 상태를 선택하고 공개 반영하세요. `모집 예정` 또는 `모집 마감`이면 상세페이지 결제 링크가 표시되지 않습니다. 일정 문의 상태의 스토어 버튼은 기존 수업 선택 링크이며 모집 확정을 의미하지 않습니다.

목록 노출 순서는 0~999의 정수이며 작은 번호부터 표시합니다. 같은 번호는 기존 수업 순서를 유지합니다. 상태와 순서는 초안 저장만으로 공개되지 않으며, 공개 반영 시 홈과 클래스 목록에 적용됩니다. DB 연결 실패 시 기존 정적 안내를 사용하므로 저장 실패 메시지를 확인하고 공개 화면도 검수하세요.

검증: lint·TypeScript·프로덕션/정적 빌드 통과. 단위 테스트 37개 통과. 홈/클래스/관리자/작업/후기 5경로 × 390px/1440px에서 가로 넘침·JS 오류 없음, axe WCAG 자동 검출 0. FAQ 마우스·키보드 토글, 클래스 필터, reduced-motion 및 JavaScript 비활성 콘텐츠 확인. 실제 DB 저장·RLS·업로드는 계정 연결 후 검증 필요.
