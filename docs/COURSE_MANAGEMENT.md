# 수업 운영 관리

## 모집 상태와 목록 순서

`supabase/course-enrollment.sql`을 `courses.sql` 이후 적용합니다. 기존 수업은 `일정 문의` 상태로 유지됩니다. 관리자에서 실제 모집 상황에 맞춰 상태를 선택하고 공개 반영하세요. `모집 예정` 또는 `모집 마감`이면 상세페이지 결제 링크가 표시되지 않습니다. 일정 문의 상태의 스토어 버튼은 기존 수업 선택 링크이며 모집 확정을 의미하지 않습니다.

목록 노출 순서는 0~999의 정수이며 작은 번호부터 표시합니다. 같은 번호는 기존 수업 순서를 유지합니다. 상태와 순서는 초안 저장만으로 공개되지 않으며, 공개 반영 시 홈과 클래스 목록에 적용됩니다. DB 연결 실패 시 기존 정적 안내를 사용하므로 저장 실패 메시지를 확인하고 공개 화면도 검수하세요.

검증: lint·TypeScript·프로덕션/정적 빌드 통과. 단위 테스트 37개 통과. 홈/클래스/관리자/작업/후기 5경로 × 390px/1440px에서 가로 넘침·JS 오류 없음, axe WCAG 자동 검출 0. FAQ 마우스·키보드 토글, 클래스 필터, reduced-motion 및 JavaScript 비활성 콘텐츠 확인. 실제 DB 저장·RLS·업로드는 계정 연결 후 검증 필요.

## 사진·영상 상세페이지

- 수업 상세페이지 관리에서 JPG/PNG/WebP(각 10MB 이하), MP4/WebM(각 50MB 이하)을 합계 20개까지 선택할 수 있습니다. MOV는 MP4(H.264 권장)로 변환하세요. 브라우저에서 재생할 수 없는 파일은 업로드 전에 거부합니다.
- 자료별 설명은 필수입니다. 본문·영상 대본은 5,000자까지 추가할 수 있습니다. 음성 및 중요한 시각 정보는 텍스트로 함께 제공하세요. 위로/아래로 버튼으로 사진과 영상을 섞어 배치하며, 첫 번째 사진이 공고 대표 이미지가 됩니다.
- ‘상세페이지 미리보기 열기’로 편집본을 확인한 다음 초안 저장/공개 반영을 선택합니다. 기존 사진 경로는 호환됩니다. 제외는 공개 목록에서 제거하는 동작이며 파일 영구 삭제는 아닙니다.
- `supabase/course-media.sql`을 courses.sql 다음에 한 번 적용해야 합니다. 기존 등록·노출 순서 기능에는 course-enrollment.sql도 필요합니다. 영상은 비공개 course-videos 버킷에 저장되며 관리자와 공개 수업이 참조하는 파일만 읽을 수 있습니다. 미적용 시 저장 실패를 표시합니다.
- 고객 상세페이지에 원본 비율의 사진·영상과 본문이 순서대로 표시됩니다. 영상은 자동 재생하지 않고 controls/playsInline/preload=none을 사용합니다. 미디어 서명 URL은 1시간 유효하며 공개 해제 후에도 발급된 URL은 만료까지 유효할 수 있습니다. 공개 화면은 내용 갱신 때 기존 미디어 URL을 재사용해 재생 중단을 줄입니다.
- 영상은 원본 업로드이며 자동 압축/트랜스코딩/메타데이터 삭제는 하지 않습니다. 공개 가능한 파일을 준비하세요. 사진은 기존대로 JPEG 변환·메타데이터 제거 후 저장합니다.
- 계정 미연결 관리자에는 로컬 체험을 제공합니다. 파일은 서버로 전송하지 않으며 현재 탭에서만 미리보기/순서/본문 편집이 가능하고 새로고침하면 사라집니다. 실제 고객 페이지 저장과 공개는 연결 후에만 가능합니다.

첨부 기능 검증（2026-11-02）: 단위 테스트 40개 통과. PC/모바일 로컬 파일 선택·영상 재생·순서 변경·본문 표시·제거·잘못된 영상 거부·새로고침 초기화·서버 업로드 없음 및 axe 검사 통과. 모의 Supabase에서 관리자 영상 업로드→초안 저장→공개→고객 상세 재생 통과. 모의 검증은 실제 원격 권한/저장 검증을 대체하지 않습니다.

## 블로그형 작성 화면 수정

눌리지 않는 비활성 등록 예시를 제거하고 미연결 관리자 맨 위에 글 작성 화면을 배치했습니다. 글 종류·제목·본문·파일 첨부·미리보기 순서로 작성합니다. ‘내 브라우저에 임시저장’은 IndexedDB에 글 1개와 첨부 Blob을 저장하며 다시 저장하면 대체합니다. 새로고침 후 ‘임시저장 불러오기’로 복원할 수 있습니다. 기존 편집 중인 글이 있으면 교체 확인을 받습니다. 저장 공간 오류는 실패로 표시합니다. 브라우저 데이터 삭제/다른 기기로의 이동에는 보존되지 않으며 서버 업로드·고객 공개가 아닙니다.
