# 후기·작업 예시·인스타그램 관리

2026-10-23 요청을 반영했다. 기존 수업 정보는 유지한다. WK Creative Studio URL은 환경 프록시 CONNECT 403으로 열지 못했으며 실제 화면/모션을 확인하거나 복제하지 않았다. 지정 브랜드 팔레트와 새로 작성한 CSS로 스크롤 등장·히어로 등장·카드 호버/키보드 반응을 적용했다. OS의 동작 줄이기 설정을 따른다.

## 운영자 흐름

1. `/admin`에서 운영자 로그인.
2. ‘후기·작업 예시’에서 공개할 곳을 선택하고 사진·제목·설명·사진 설명을 입력한다. 공개 동의를 확인하고 비공개 저장한다.
3. 등록 목록에서 공개하기를 누르면 후기는 홈/후기 페이지, 작업 예시는 홈/WORK에 표시된다. 제목·설명·분류 수정 시 다시 비공개가 되므로 확인 후 공개한다.
4. ‘릴스·게시물’에 Instagram 공개 게시물/릴스 공유 링크와 소개를 입력한다. 비공개 저장 후 공개하기를 누르면 홈페이지 Instagram 영역에 나타난다. 수정·비공개 전환도 가능하다.
5. 수업 커리큘럼·상세 사진·가격·상품 링크는 기존 수업 관리 영역에서 관리한다.

## 연결 조건

Supabase에서 `reviews.sql` → `courses.sql` → `showcase.sql` 순으로 적용한다. 이미 앞의 두 파일을 실행했다면 `showcase.sql`만 실행한다. 기존 후기는 기본 kind=review로 보존한다. 관리자 UUID 등록 및 공개 환경변수 설정은 `REVIEW_MANAGEMENT.md` 참고. 외부 프로젝트는 아직 연결되지 않았으므로 실제 저장·권한 E2E는 미완료다. 미연결 `/admin`은 disabled 입력과 안내가 있는 관리 화면 미리보기이며 가짜 저장을 하지 않는다.

익명 API 접근 시 published 항목만 조회 가능하고, 관리자만 작성/수정/공개할 수 있다. review 사진은 기존 비공개 버킷 RLS를 사용한다. 게시물 공개 동의 및 사용 권한은 운영자가 확인한다.

## Instagram 표시 방식

자동 계정 수집/API 연동은 하지 않는다. 운영자가 지정한 공개 게시물 링크만 저장한다. 프로필/다른 호스트/스크립트/비정상 경로는 거부하고 공유 링크의 추적 쿼리를 제거한다. URL만으로 계정 소유권이나 임베드 허용 여부를 검증할 수는 없다.

방문자가 ‘여기서 릴스/게시물 보기’를 누르기 전에는 Instagram iframe/script/이미지를 요청하지 않는다. 버튼 옆에 외부 연결 안내를 표시한다. 클릭 후 Instagram 공식 embed 경로를 iframe으로 표시한다. 공개 계정/게시물의 임베드 허용 여부, Instagram 정책·쿠키·로그인에 따라 재생이 제한될 수 있으므로 원본 링크를 항상 제공한다. HTML 스니펫 입력은 받지 않는다.

실제 계정 릴스 URL이 아직 제공되지 않아 실제 Instagram 재생은 미검증이다. 고객 후기/예시/릴스 내용을 지어내지 않고 비어 있는 영역에는 안내만 표시한다. 실제 콘텐츠는 운영자가 계정 연결 후 등록한다.

## 검증

홈·관리자·WORK·후기 PC1440/모바일390 총8개 화면에서 응답·가로넘침·JS 오류 및 axe WCAG2 A/AA·2.1AA 자동 검사 통과. 새 블루 섹션의 설명문 대비를 수정했다. reduced-motion에서 등장 모션 생략, JS 비활성에서 본문 노출 확인. 자동 검사는 전체 수동 접근성 인증을 의미하지 않는다.

lint·프로덕션 빌드 통과. 단위 테스트36개 통과(Instagram URL 정규화 및 악성/프로필 주소 거부 포함). 모의 Supabase API를 사용한 Chromium에서 작업 사진 등록/분류/공개와 홈/WORK/후기 분리, Instagram 비공개 등록/공개/URL 정규화, 보기 전 외부 요청0, 클릭 후 iframe/닫기 및 모바일 가로폭을 확인했다. 실제 원격 SQL 권한과 Instagram 재생은 이 검증 범위에 포함하지 않는다.
